CulturalDynamics.jl

Simulação de Disseminação Cultural — Modelo de Axelrod estendido

Parâmetros do Modelo

Tamanho do Grid 31×31
Número de agentes = N²
F — Dimensões Culturais 5
Quantos aspectos culturais cada agente possui
Q — Níveis de Adesão 3
Opções possíveis em cada dimensão (1=nunca, Q=sempre)
Passos de Simulação 300
Quantos passos temporais executar
ε — Bounded Confidence 0.3
Limiar de similaridade para interação (0=sempre, 1=nunca)
Taxa de Mutação 0.00
Probabilidade de mudança aleatória por traço (0=desativado)
